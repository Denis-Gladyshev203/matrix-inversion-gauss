# Обращение матриц методом Гаусса–Жордана

Программа на языке C для решения задачи обращения квадратных матриц произвольной размерности $N \times N$ методом Гаусса–Жордана с выбором главного элемента по строке.

---

## Основные особенности реализации

1. **Соблюдение ограничений по памяти:**
   - Все матрицы располагаются в **непрерывных блоках динамической памяти** (`double*`), что обеспечивает максимальную локальность данных для L1/L2 кэша процессора.
   - Суммарный объем выделяемой памяти строго ограничен величиной $2n^2 + O(n)$.

2. **Модульная архитектура без динамического выделения внутри алгоритма:**
   - Вся память под матрицы и вспомогательные векторы (`col_perm`, `temp_buffer`) выделяется **единоразово в `main`**.
   - Вычислительная подпрограмма `gauss_invert` не содержит вызовов `malloc`/`free`.

3. **Инициализация данных:**
   - Поддержка чтения матрицы из текстовых файлов ($k = 0$) с проверкой формата.
   - Генерация матриц по формулам ($k = 1 \dots 4$), включая плохо обусловленную матрицу Гильберта ($k = 4$).

4. **Оценка точности (Норма невязки):**
   - Вычисление бесконечной нормы матрицы невязки $$\Vert{}A A^{-1} - E\Vert{}_\infty = \max_i \sum_j \vert{}(A A^{-1} - E)_{ij}\vert{}$$.
